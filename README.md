# Linux Bash Scripts

A collection of bash scripts for Linux system administration and monitoring.

## Scripts

| Script | Description |
|--------|-------------|
| `logger.sh` | Logging utility with timestamps |
| `retry_check.sh` | HTTP check with retry logic |
| `batch_url_check.sh` | Check multiple URLs from file |
| `cleanup.sh` | Delete files older than 7 days |
| `getopts_check.sh` | Port check with flag arguments |
| `trap_script.sh` | Cleanup on exit with trap |
| `system_report.sh` | Disk, memory and CPU report |
| `project_github.sh` | Full system monitor (final project) |

## Skills practiced
- Functions with local variables
- Arrays and loops
- getopts flag parsing
- trap for cleanup
- curl HTTP checks
- ping server monitoring

## Environment
- macOS / Linux
- Bash
